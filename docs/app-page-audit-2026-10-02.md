# 整体 App 页面扫描清单

日期：2026-10-02。范围：zjh 宿主 + 默认 Jolly。下面保留原始扫描结果；后续修复与验证记录见文末。

扫描基线：zjh-dynamic `98e8bda`，zjh-plugin `d5c0b20`；扫描前两个仓库工作区干净。

本次是**源码全页面审计**：检查宿主全部 15 个具名页面、动态应用承载页、启动/失败/更新状态，以及 Jolly 首页、工坊、需求整理、反馈确认和弹层。检查页面对应请求、存储、导航、账号作用域、共享组件。遵循仓库约定，未运行独立类型检查、测试或预览，也未连接 Android 真机。因此“确认”表示可从代码确认机制或缺失；性能条目确认实现风险，但没有 FPS、耗时、内存实测；“待验证”不得视为已经复现的 UI bug。其他动态安装的第三方应用不在本次范围。

优先级：P1 = 优先修复，涉及内容丢失、核心功能或显著性能风险；P2 = 常规修复；P3 = 体验优化。本次未确认 P0 问题。

代码位置均相对于对应仓库根目录；Jolly 文件属于 zjh-plugin，其余属于 zjh-dynamic。
