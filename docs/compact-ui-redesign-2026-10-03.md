# 紧凑 UI 改版与页面审查

日期：2026-10-03。范围：zjh-dynamic 的全部 15 个具名宿主页面、动态应用承载、启动与更新状态，以及共用的主题、按钮、表单、图标和动态框架。

这是源码实现和源码级审查记录。遵循仓库约定，没有运行独立类型检查、测试、预览或真机验收，没有发布。zjh-plugin 的 Jolly、工坊及第三方应用业务布局不属于本次宿主源码改动，应用可以继续通过稳定的共享 UI 契约使用主题。

## 设计方向

原有界面使用天蓝画布、珊瑚强调色、偏大的圆角与软陶阴影。Pressy 会根据填色自动追加尺寸、内边距、圆角和阴影，覆盖调用方意图，紧凑按钮与文本操作尤其容易被撑开。我的页面以多组相似设置行组织所有入口；作者主页纵向堆叠头像、身份与统计；外观设置的文字与真实配色不一致。

此次按全面改版处理。视觉变化 7、动效 6、密度 8：石墨 / 冷白与银灰作为底色，酸橙用于主操作与选择；错误和其他语义状态继续使用现有语义色。保留品牌名称、稳定路由、应用 ID、模块范围、存储键、请求和工坊确认流程。

- 正文以 14-15 点为主，详情正文 16 点；依靠字重和层级组织信息。
- 页面边距 16，紧凑单元内边距 8-12，分组间距 8-12。
- 控件圆角 8，信息面 12-16，头像视上下文使用圆形或 12 点圆角。
- 常规操作保持 44 点触控区域。列表作者链接保留紧凑尺寸，需在真机检查可触达性。
- Pressy 提供按压与回弹，不再强制覆盖调用方的圆角、内边距或阴影。旧 SDK 消费者只传主色填充时仍有紧凑的缺省内边距。
- 分类与主题选择使用一个弹簧滑块；导航选中面、页面进入、下拉刷新、点赞和更新提示提供状态反馈。
- 动效使用现有 Reanimated。新增动画尊重系统减少动态效果设置；图标使用现有 Lucide 依赖，没有新增原生库。

## 页面覆盖

| 页面 / 状态 | 实现与审查重点 |
|---|---|
| 动态首页 | 横向应用快捷条、紧凑分类、强调色发布入口、通知数字对比、底栏留白与滚动收起反馈 |
| 应用市场 | 搜索与清空、横向分类、真实首项应用展示、紧凑目录；首项不在目录重复，筛选后恢复完整结果 |
| 我的 | 横向资料区、作品和引擎两个快捷入口、紧凑偏好列表、长昵称与更新状态 |
| 应用 / 作品详情 | 介绍与元信息重新分组、次要操作并排、固定主操作、真实截图、分享编辑后的标题一致性 |
| 我的作品与应用 | 滑动分段选择、新建入口移入顶栏、结果数量、长标题、摘要截断与操作换行 |
| 登录 / 个人资料 | 统一聚焦表单、紧凑按钮与头像、验证码倒计时、忙碌禁用、退出登录的语义色 |
| AI 引擎 | 紧凑配置单元、引擎进入动画、图标操作对齐、字段聚焦和可读标签、未保存确认保留 |
| 动态小结 | 分离运行状态与频率设置、立即整理主操作、错误与重试、自定义输入 |
| 外观 | 滑动选择、真实主题色样与文字层级示例、配色描述同步 |
| 应用信息 | 版本和本机安装大小集中展示，技术详情继续按需展开 |
| 应用修改反馈 | 共用顶栏、紧凑多行输入与截图区、带回工坊主操作，原确认流程与草稿机制保留 |
| 发动态 | 紧凑作者与编辑区、图片 / 应用工具条、自动保存提示、字数、发布禁用、选择弹层安全区 |
| 动态详情 / 评论 | 紧凑正文与评论标题、聚焦评论输入、固定发送区、回复状态、无动画导航时仍可加载评论 |
| 通知 | 可读的全部已读操作、紧凑未读条目、两行正文摘要、元信息和操作反馈 |
| 作者主页 | 横向头像与身份、紧凑统计、滑动分段选择、切换后回到顶部、无作者跳转时头像正常显示 |
| 动态应用承载 / 失败 | 延迟加载状态、友好失败说明、实际重试入口、渲染失败后的重载与返回 |
| 启动 | 品牌与短加载状态，适配深浅主题 |
| 更新提示 / 更多菜单 / 图片查看 | 紧凑操作、进入退出反馈、底部安全区、减少动态效果、大图关闭入口 |

## 已完成的静态验证

- 修改过的 TS / TSX 源码通过 TypeScript 语法解析；这不等同于类型检查或运行验证。
- 对新增使用的 26 个 Lucide 导出名以及 Reanimated 的减少动态效果、循环动画接口核对了本机安装的库声明。
- 校验共享主题的颜色对比：深色最弱正文 5.59:1，浅色最弱正文 4.61:1；主按钮文字 12.49:1；输入框边界深色 3.16:1、浅色 3.63:1。这里覆盖共享 token 组合，不代表所有插件自绘内容均已通过可访问性验收。
- 对全部具名宿主页面逐个检查了源码中的顶栏、布局、长内容、字段、禁用与错误状态；保留虚拟列表、分页、账号隔离、草稿与发布保护。
- 没有改动运行时公共模块键、应用 manifest、SDK 公共入口签名或原生依赖版本。
