## 验证边界

没有单独运行类型检查、测试、独立预览或发布，遵循仓库默认规则。Babel 编译不是完整 Metro／Hermes 构建，静态审查不是实际设备验收。

全仓默认 premium 扫描在未修改的 packages/ui/beautiful 与 shadcn 中报告 13 个 actionless-button 匹配；未为本轮动态页改造修改这些共享库。宿主范围审查通过不代表全仓检查通过。

## 待真机验收

320 / 360 / 412 宽度与系统字体缩放；深浅主题与底部安全区；动画解码、暂停、后台返回、减少动态效果；分类归顶、头尾滚动、下拉刷新；空列表、失败重试、加载更多、发布入口、作者／应用导航、点赞与大图。需要实际设备截图与交互结果后再迭代排版。
