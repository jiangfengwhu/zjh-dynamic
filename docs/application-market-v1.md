# 应用市场第一版

底部为动态、应用市场、我的。市场由平台提供，工坊与制作进度归 Jolly；SDK navigation.create(prompt) 带需求打开 Jolly 内的工坊。旧包的 agent Tab 请求仍兼容转入 Jolly。

GET /v1/market 仅提供显式公开的版本；内置官方应用只有 Jolly。条目携带不可变 manifest、真实作者身份与原作信息；浏览和安装无需登录，创作与上架验证账号，不自动公开工坊候选。

列表按最新公开版本发布时间排序，编辑名称、介绍、分类和截图不刷新发布时间，同版本重发保持排序。支持工具、效率、生活、创意、其他分类和服务端关键词搜索。`GET /v1/market?limit=24&category=tools&q=...&cursor=...` 返回 applications 和 nextCursor，limit 为 1–50；游标绑定筛选条件，按发布时间和稳定应用 ID 翻页。appId 详情和 authorId 作者主页查询仍可不传 limit。市场只读取 shared 公开记录，不消费候选版本。

列表使用 FlatList，按筛选条件缓存已加载页和滚动位置，内存最多 12 个筛选视图。返回 60 秒内不重复请求，缓存过期在后台同步首页并保留已加载页；手动刷新重新建立列表。点进详情重新读取公开记录，撤回应用不会从缓存误进入候选包。安装前检查平台兼容性，通过原生缓存下载并校验包体与媒体。运行中应用更新会重载 JS。

作者发布和编辑市场信息时可选择分类、上传最多六张截图，首张为列表预览；详情支持横向浏览与全屏查看。使用现有 RN ImagePicker 和 FastImage，不引入新原生依赖。客户端压缩成 JPEG（最大 1600×2400、质量 0.75），通过宿主原生文件传输上传 R2。`PUT /v1/market-media/:appId` 验证登录、作品作者与 X-Workshop-Token，单张最大 2 MB，每账号每天最多 60 次上传。图片按应用、作者和内容哈希保存；发布时拒绝外部 URL、其他作者/应用截图及未上传文件。图片不可变缓存，撤回和移除截图不删除已上传对象；未引用截图的自动清理后续再做。

截图、分类属于公开展示信息，不参与应用包哈希或 SDK 契约。浏览无需鉴权，详情直接提供安装体验和基于它创作两个入口，创作时才登录。安装与目录变化实时通知宿主和动态页。

我的应用显示本机安装记录，支持打开、更新和卸载。卸载从本机目录移除，重载以释放执行中的模块和计时器，保留本机数据及下载缓存供重装恢复。Jolly 是默认伙伴，不能卸载。动态只显示已装应用，其历史数据不删除。

Jolly 主页提供工坊入口和最近心愿；工坊提供创作、进度和体验；制作完成后可继续迭代，作者主动决定上架。登录归属、上架和独立 Remix 已由平台提供。
