# 紫金花 UI / UX 重设计

范围为 RN 平台的全部页面、Jolly 首页与创作流程。独立第三方应用的业务画布和动态内容仍由各插件自己绘制，不给应用页面添加平台悬浮控件。

`index.html` 是离线交互设计稿，含 32 个页面与流程状态。左侧切换页面，右侧切换深浅主题、加载、空白、失败和离线示意。内容为示例；登录、邮件、AI、上传与发布不访问真实服务。RN 实现保留已有接口和业务约束，未新增模型服务或内置应用。

## 视觉与布局

- 浅色白色画布 `#FFFFFF`，淡紫重点区域 `#F0ECFA`，主操作 `#644BC1`，正文 `#24232C`，辅助文字 `#74717F`。
- 深色画布 `#19181F`，重点色 `#BAA6F3`，正文 `#EEECF5`，辅助文字 `#AAA5B8`。
- 页面水平边距 12–16，控件内距 10–12，组内间距 6–8，组间间距 12–16。
- 标题使用平台无衬线字体，页面标题 19，列表标题 15–16，正文 16，辅助文字 12–13。保留系统字体缩放。
- 普通面板圆角 10–12、细边线、无装饰渐变。弹层使用轻阴影，头像保持圆形，视频角色保留。
- 可点击区域原则上至少 48 dp；紧凑指视觉布局，不把点击区域压缩到难以操作。

## 动效与状态

| 对象 | 触发 | 反馈 | 时间 |
| --- | --- | --- | --- |
| 普通按钮 | 按下 / 松开 | 最小缩放 0.96，无明显弹跳 | 100 / 160ms |
| 主导航图标 | 切换 tab | 1px 位移与透明度 | 160ms |
| 主题分段控件 | 点击 | 淡色底短位移 | 180ms |
| 页面 | 进入 / 返回 | 沿用原生 stack 转场，准备好布局再进入 | 平台控制 |
| 进度 | 服务端状态变化 | 更新同一块内容，详细日志默认折叠 | 不生成假百分比 |

基础按钮、主导航、主题切换尊重系统减少动效设置。所有实际请求沿用现有 loading / 防重复 / toast / 草稿处理。设计稿中的验证、登录和发布是模拟交互，不能作为真实业务验收。

## 实现原则

沿用应用 ID、数据键、权限与运行时契约。没有数据库迁移；没有增加第三方原生依赖；SDK 公共类型不变。公共 UI 组件从宿主运行时供插件使用，因此视觉更新随宿主包发布。Jolly 业务页面单独构建并官方发布。
