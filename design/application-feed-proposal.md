# 生花应用内容流试验

状态：已实现宿主试验版，按用户要求通过正常动态包流程发布；手机原型使用示例内容，不连接线上服务。长期约束见根目录 DESIGN.md，本文记录本轮产品方案与未验证事项。

## 本轮决定

参考 Loopit 的即时互动作品形式。首页中央直接运行真实应用，不要求创作者另做视频、预告或体验页面。靠下方的独立区域用于切换，中央触摸全部交给应用。

当前入口仍是各应用现有首页。能否打开即理解、立即参与，需要在真机上检查代表性作品，再决定如何改进创作指引；第一版不新增 SDK 体验入口契约。

## 导航

- 首页：公开作品流，一屏一个应用；当前沿用公开列表顺序，不宣称个性化推荐。
- 社区：迁入推荐动态与关注动态，顶部分类居中、不展示头像，保留横向原生分页、独立列表状态和新内容提示。
- 中央发布动作：制作应用 / 发布动态，制作应用位于首位并默认选中；显式分享和动态草稿进入发动态。
- 通知：沿用互动、制作进度与私信入口。
- 我的：作品在首位并默认选中，其后为动态。

分类、搜索和本机安装管理收进首页右上角「发现与搜索」。搜索页作为独立路由使用自身分页与手势，不依赖主导航抽屉上下文。公开版本、作品介绍与管理能力保留，文案由「市场上架」改为「公开作品」。内部路由、接口和存储键继续复用，以免破坏已有导航与数据。

## 手机布局

顶部是头像入口、发现作品标题与搜索。中央是圆角应用舞台，保留用户主题与真实应用页面。底部互动区左侧依次是点赞、评论、收藏，右侧是分享、详情，仅显示图标；第二行显示作者、作品名与紧凑的改编入口，作品名下补充最多一行简介。整个底部互动区支持上下滑动切换，不在应用侧边放悬浮操作列。

再下方是独立的切换手势区，位于固定主导航之上，支持上下滑切换，主导航原首页槽位改为下一条箭头，点击也可切换。底部不展示切换说明。宿主外框与应用主题上下文跟随明暗外观。首页画面外使用与其他页面相同的氛围渐变，底部导航统一使用悬浮圆角条。

不显示未经服务端提供的点赞、收藏、播放量等数字，也不加入无法真正完成的互动按钮。

## 切换与触摸

- 只有从下方切换区起手的纵向拖动切换应用；上滑下一条，下滑上一条。
- 拖动时当前舞台跟手移动，相邻缓存实例参与动画，尚未准备好的实例显示加载骨架。
- 点击底栏下一条箭头执行相同切换；边界不无限循环，末尾可以刷新或重试分页。
- 中央滚动、拖动和绘图不触发换页。首页通过头像打开抽屉，禁用宿主抽屉横滑，避免抢走应用手势。
- 系统/SDK 返回优先离开内嵌体验，展示继续体验入口；缓存实例保留内部状态，超出缓存队列后未保存状态不保证恢复。
- 首页保留作品索引，社区保留自己的分页和滚动位置。

## 加载与版本

最多缓存当前、后续 10 个和最近浏览的 10 个应用实例；稳定 key 保留内部状态，React Activity 在隐藏时清理组件效果、显示时恢复。刷新、切换账号和超出队列才淘汰实例。

复用公开版本、兼容性、完整性和执行权限校验。当前应用就绪后，空闲时完整加载接下来的 10 个作品代码、资源与入口，并用 Activity 预渲染隐藏页面；隐藏页面不建立组件效果，随滑动补齐队列；列表剩余 14 条时获取下一页元数据。前后台加载合并准备任务。原生已开始的下载无法取消，任意作品自身的异步初始化不能保证瞬间完成。

体验不会将作品固定到用户安装目录；执行过程中仍会生成运行时必要的版本、资源和健康记录。本机其他版本、私有制作候选或已驻留的不同版本，不被浏览操作覆盖，提示通过详情管理。

队列淘汰时卸载 React 视图，已经执行的 JavaScript 模块、应用自行创建的全局任务及资源不保证自动回收。需要真机评估连续浏览的资源增长，不能将其视为已解决的隔离运行机制。

## 验证范围

已完成本地 Metro / Hermes 动态包构建和源码依赖解析，尚未进行真机视觉与交互验证。发布状态以发布命令结果及线上清单核对为准。

真机优先检查：

1. 游戏、画布、长列表的中央手势是否独立；下方区域是否容易触及。
2. 首次加载、快速连续切换、断网和失败重试是否仍可继续浏览。
3. 内嵌页面的安全区、键盘、弹窗与完整打开是否正确。
4. 切换社区、进入后台、账号切换和版本冲突时的状态是否符合预期。
5. 连续体验大量作品后的内存、声音、定时器和全局任务是否可控。

## 后续候选能力

关注作品流、个性化推荐、收藏浏览页和最近使用、结果回流社区、更完善的运行生命周期，以及应用场景入口均未在本轮实现，需要分别验证价值与数据契约。

先观察开始有效操作、得到结果、再次使用及创作的行为，不以刷动时长单独判断成功。

交互原型：同目录 application-feed-concept.html。原型中的即时操作使用演示逻辑，原生宿主试验版使用真实公开应用。

互动区左侧为点赞、评论、收藏，右侧为分享、详情，仅展示图标；作者和改编入口保留下一行。作品讨论跨版本保留并独立于社区动态，收藏按账号同步。

首页评论以当前应用上方的底部面板展示，不跳转社区动态详情；支持分页、回复、发送、删除自己的评论和草稿保留。
